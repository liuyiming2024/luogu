验证日期：2026-11-20。全程本地编译 g++ -std=c++17 -O2 + 独立正确解对拍，不登录、不提交。 本批起改为三类，并按新口径重判前 3 批，以本文件为准。

0. 口径更新（本批起固定）

代码只是辅助，不判「全不全」

题解作者本来就没有被要求贴出完整可提交代码。因此：

  • 取到代码片段时，我补最小外壳（#include、int main 返回类型、必要全局变量声明）后再编译；
  • 补齐的部分一律不计入题解缺陷；
  • 只验证核心逻辑对不对，不评判代码完整不完整。
  • 由此，前几批里「缺头文件 CE」「老式 main(){}」「页面渲染吞字符」不再作为缺陷判定，统一移到乙类记一笔。

2.1 P4995 up402yw6 · 丙

补最小外壳后核心（逐字）：

#define int long long
int h[300 + 9];
sort(h + 1, h + n + 1);
int lt = 1, rt = n, t = 0, now = 0;
for (int i = 1; i <= n; i ++) {
    if (i % 2 != 0) { t += (now - h[rt]) * (now - h[rt]); now = h[rt]; rt --; }
    else            { t += (now - h[lt]) * (now - h[lt]); now = h[lt]; lt ++; }
}
cout << t;

独立正确解：状压 DP dp[mask][last] 枚举全部跳跃顺序求最大值，不依赖贪心结论。 样例 1 2 / 2 1 → 5 ✓；样例 2 3 / 6 3 5 → 49 ✓；n=1 → 10000 ✓；120 组随机（n≤9）0 不一致。 数组 h[309] 对题面 n ≤ 300 刚好够，#define int long long 也挡住了 h ≤ 10⁴ 时平方和约 3×10¹⁰ 的溢出；n=300 上界跑通。

2.2 P1216 tneoku44 · 丙

int a[1001][1001],n;
for(int i=0;i<n;i++) for(int j=0;j<=i;j++) cin>>a[i][j];
for(int i=n-1;i>0;i--) for(int j=0;j<i;j++) a[i-1][j]+=max(a[i][j],a[i][j+1]);
cout<<a[0][0];

0-based 下三角存法 + 自底向上原地累加，与标准 DP 120 组随机（含 n=1000）+ 全 0 / 全 100 边界 0 不一致。数组对 r ≤ 1000 够用，int 对值 ≤100 够用。

3.2 P1002 滚动数组版 — 数组尺寸笔误（本批新增）

long long f[23];

void work(long long x,long long y){ ... ma[x+2][y+2]=true; ... }

3.3 P1018「不带高精度」示意代码篇 — 主动简化的辅助代码（本批新增）

作者原文：「为方便理解附上一个不带高精度的代码。带高精度的写法建议用类类型或者结构体并重载运算符实现」，代码为 long long dp[N][N]。N≤40 时结果远超 long long，必然溢出——但作者已明说这是思路示意、不是完整解法。按本批新口径：这是辅助代码，不拿类型不够去 hack 它，归乙类。
