最终要求 · 口径锁定（8 条澄清）

来源：两张手写「最终要求」+ 2026-11-27 逐条澄清。此文件为最终口径， 与此前任何推测冲突时以本文件为准。
#我提出的疑问锁定答案
1「2. 架构，主要数据源……」被涂黑处自己维护一个数据源，就是这个 GitHub 库。不依赖外部官方数据源
2「且不 N WA」因为取不到官方数据，所以用 std 对拍；std 支持工单（投稿）；投稿先与原 std 对跑比较，去除 WA 与不优的，再进入人工审核
3Webnote 是否正确 / 划掉的词平台为 GitHub / Supabase / Webnote，划掉的是写错了，不计
4「skk 的头像」默认头像看 luogu：未登录 / 无法联网取头像时使用洛谷默认头像
5「无交(?) 时使用灰色」无效（无缓存且无网） → 用户名灰色；有缓存或联网时用主题色
6C++/Python/C 之外那个语言无，就这三个（不额外指定语言）
7隐私声明中提供「?条款」此条：把「延迟维护 / 源已删则本地也删 / 跟踪保存站工作流与洛谷工单」写进隐私声明作为条款
8另一个低频检索账号两个标识拼写差一个 i，按最终要求原样并列、未擅自合并；具体字符串与凭据不在公开仓库明文登记，仅由本人持于 Settings Secrets / 本机
9评论持久化直接推洛谷：评论的权威持久层是洛谷文章评论区，不另建评论数据库；用用户个人账号推。本地只留离线副本 + 待推队列（离线可看），低频检索账号不参与评论
10真编译可以要求对方联网且登录，用对方自己的账号借洛谷 IDE 真编译。不再自建 runner / WASM：新窗口打开洛谷域下的 IDE，登录态自然生效，代码走剪贴板；离线兜底仍用 std 期望输出对照
11风险归属让对方自己确认后果、自己承担：所有写操作 / 借账号动作前弹确认门，列明账号、平台痕迹、风控与版权责任，勾选 + 输入「我自担」才执行；默认每次确认，用户可主动选择会话内不再提示
12运行态 / 自用 / 代提交运行态可以自己加、自己下载：静态站只是壳，GitHub Actions runner 即现成运行态，本机也可跑。项目按单人自用设计，公开产物不再出现角色字样、不再明文登记账号。评论 / 发文 / 洛谷 IDE 评测 → 本地待推队列 → 自动写回仓库 outbox → push/定时触发 Action 自动低频代提交 luogu。凭据走 Secrets
13本人不用提交首次一次性授权即可：在 Settings → Secrets 写一次 LUOGU_SUBMIT_CONSENT；之后本人不用 push、不用手动跑工作流、不用每次填确认值。前端配一次 fine-grained token 后，「导出待推队列」直接写入仓库；未配置 consent 则永远只预览
14授权与 token 由本人自行上传自动化唯一不能代劳的是授权本身：LUOGU_SUBMIT_CONSENT 是「本人自担后果」的意思表示，代填等于替本人确认；洛谷登录态不接收、不代持。由本人自行上传 token 并自己授权，仓库文档给出精确保存路径（浏览器 localStorage["ll:gh_token"] / 仓库 Settings Secrets / 本机 ~/.config/luogu_submit/env）。我不接收任何 token 明文

由澄清带出的全局约束

  • 离线优先：本地 HTML 浏览与发文；发文先本地保存；只有「已登录洛谷账号 + 联网」才回推 luogu.com.cn
  • 评论推洛谷：本地先存 → 待推队列 → 由「能出网且持有登录态」的一端低频推洛谷；

静态 Pages 绝不直接 fetch 洛谷（跨源 + HttpOnly cookie + CSRF 不可达），详见《架构可达性测试报告》

  • 本库即数据源：文章 / 讨论区 / 题面 / 工单四类内容自行维护；联网用户浏览时抓取所浏览内容、延迟维护，源已删则本地也删
  • std 准入：对拍 → 去 WA 与不优 → 可选工单 → 人工审核无错 → 迁入 std
  • 只认 token 不认人：所有管理/API 能力以 token 为准，不校验自然人身份
  • 账号使用：两个低频检索账号仅用于「审 std / 删资源」；本人持有的低频检索账号（凭据仅存 Secrets / 本机） 仅在这类低频、无风险、必需的请求里使用
  • 真编译：借洛谷 IDE、用用户个人账号、联网已登录（第 10 条），静态站不碰登录态
  • 后果自担：确认门是明示同意与责任划分，不是安全边界；真鉴权仍靠 token（第 11 条）
  • 不落凭据：账号、密码、cookie、token 一律不写进公开仓库；只走环境变量 / Actions secrets / 浏览器本地缓存
  • 单人自用：不设角色体系；所有能力以「本人 + token」表述，公开页面与文档不出现角色字样
  • 运行态自加：静态 Pages 不承担运行态；Actions runner / 本机脚本由使用者自行添加或下载
  • 自担后果：本人首次一次性授权（Secret），之后自动提交；前端每笔仍过「我自担」确认门。未授权则预览态不向洛谷发任何写请求
