按"验核心逻辑对不对、不判全不全"的要求，本批有 2 次假命中是我自己的问题，已纠正，不计到题解头上：

② P1164 ipduooli — 我补外壳时漏抄了题解原有的一行。 首版补最小外壳时漏掉 for(int i=1;i<=n;++i) dp[i][0]=1;，导致 103 组假 WA。回原文逐字复核后确认该行存在，补回后 200 组 0 不一致。这正是"代码只是辅助"最容易踩的坑：片段取不全时，错在我这边。

2. 丙类逐篇（6 篇）

2.1 P1164 2yru0rav

三段式 if(j==a[i]) f[i][j]=f[i-1][j]+1; if(j>a[i]) ...+f[i-1][j-a[i]]; if(j<a[i]) f[i][j]=f[i-1][j]; 看似漏了 dp[0][0]=1，但 j==a[i] 的 +1 恰好补上"只选这一道菜"的空集项，与标准二维计数 DP 等价。官方样例 4 4 / 1 1 2 2 → 3 ✓，250 组随机 0 不一致。

2.2 P2240 bv44vwt6

x = w/v 用 double 存单价，cmp 返回 a.x>b.x。v,w ≤ 100，最小单价比差约 1e-4，远大于 double 精度，排序不会错；if(weigh) 把容量耗尽后的循环空转挡掉。独立解用 Fraction 精确贪心 + half-even 舍入，300 组 0 不一致。

2.3 P1060 0hps6y5z（二维版）

for(j=n;j>=1;j--){
    b[i][j]=b[i-1][j];                       // 复制上一行
    if(j>=v[i]&&b[i-1][j-v[i]]+v[i]*p[i]>b[i][j]) b[i][j]=b[i-1][j-v[i]]+v[i]*p[i];
}

先复制再判断，是完整正确的二维 01 背包。250 组随机 0 不一致。 作者注释自述「贪图省事没把 j>=v[i] 改成 j>=1，结果有一个数据点没过，讲道理这里应该算致命错误的」——但最终贴出的代码下界就是 j>=1 且含复制行，自述描述的是修改前版本。按"验代码不验文字"，归丙；自述作为乙类条目记一笔（§3）。

2.4 P1616 lgmnaw1h

文章给 3 个代码块：前两块（f[101][1001] 二维、f[1001] 倒序一维）是正文明确写的「以下一大段为思路回顾，可适当跳过」，讲的其实是 P1048 的 01 背包；第 3 块才是 P1616 最终代码：

long long t[10001],p[10001],f[10000001];
for(i=1;i<=M;i++) for(j=t[i];j<=T;j++) f[j]=max(f[j],f[j-t[i]]+p[i]);

正序（完全背包）+ long long + f[10000001] 对题面 t ≤ 10^7 够用。200 组随机 0 不一致。 按"代码只是辅助"，不能拿思路回顾块去 hack 最终代码——这条也记进乙类（§3）。

2.5 P1164 ipduooli

dp[0][0]=1 + for(i=1..n) dp[i][0]=1 + 逐行 j>=a[i] 累加，是标准二维计数 DP，200 组 0 不一致（见 §0②）。 附带一笔：int dp[10010][10010] ≈ 400 MB BSS，在常见内存限制下会 MLE。但按第 2 批起的口径「内存限制属资源约束，不计入」，不作为 hack 依据。

2.6 P1020 n5d7jq0b

反向扫描 + upper_bound(d+1,d+1+n,a[i]) / lower_bound(c+1,c+1+n,a[j]) 双数组，while(d[len]!=d[0]) 用 0x3f 哨兵计长。独立解用 O(n²) 求「最长不上升子序列长度」与「最长上升子序列长度（Dilworth）」。官方样例 389 207 155 300 299 170 158 65 → 6 / 2 ✓，全相等 / 严格上升 / 严格下降 / 单元素 / 两元素相等 全对，250 组随机 0 不一致。

3. 乙类新增（单列，不计 hack）

3.1 P1049 v3wxayi3 — 作者自述的随机化乱搞（本批重点）

作者原文：「rand()%9==0 这句为真的概率为 1/9，即放弃当前最优解的概率为 1/9」「这样运行一遍得到的方案不一定是最优方案，因此我们重复运行多次，很有可能某一次就能得到最优方案」，ans=v; for(int i=1;i<=100;i++) ans=min(ans,f());。

实测：rand() 未 srand，每次进程种子固定，输出可复现（同一输入连跑 5 次结果一致），所以它不是"评测机波动"，而是确定性地可能给不出最优。300 组小规模枚举对拍中命中多组，例如：
