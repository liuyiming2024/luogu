帮助手册 · 本地轻量版 luogu

纯静态、无 CDN、无外部依赖。双击 site/index.html 即可离线使用。 页面加载不发起任何网络请求；所有「联网」能力都要你主动配置或点击才启用。

1. 开始使用

想做什么怎么做
看题解首页按题号分组，搜索框输题号 / 编号 / 关键词；点卡片进文章页
看结论文章页有「归类（甲/乙/丙）」「判定备注」「甲类合法反例」「引用与署名」
看报告首页侧栏「归档资料清单」，含各批次报告、审查报告、本手册
离线直接打开本地文件；luogu_离线归档.zip 解压即用
线上GitHub Pages 已开启，地址见仓库 README

2. 登录与身份（离线优先）

  • 右上角「登录」可用 cookie 或账密；信息存在浏览器本地，子页面不重复登录
  • 未登录 / 取不到头像 → 洛谷默认头像（内联 SVG，不请求外网）
  • 用户名：联网从洛谷取；无网用缓存或登录标识
  • 无效（无缓存且无网）→ 灰色；有缓存或联网 → 主题色
  • 用 cookie 时，手机号 / uid 等标识不显示
  • 气泡、牌子等次要元素：有则渲染，没有不添加
  • 发文先本地保存；只有「已登录 + 联网 + 已配置回推 API」才推到 luogu.com.cn
当前沙盒出口无法访问外部域名，回推适配器默认关闭并在界面明示； 你在自己网络里按 api/API契约.md 接上即可启用。

3. 评论（Markdown + 验证码）

  • 每篇文章页底部有评论区，按文章隔离
  • 评论持久化 = 直接推洛谷（第 9 条口径）：本地先存离线副本 → 待推队列 →

由「设置」里开启后交给 /api/comments/push-luogu，用你个人的洛谷账号低频推到 洛谷文章评论区。洛谷是权威持久层，不另建评论数据库

  • 静态站不直连洛谷（跨源 + HttpOnly cookie + CSRF 不可达）；真正发请求的是

本机代理 / 自托管 runner / 扩展。未开启时纯本地、零请求

  • 每条评论显示状态：本地已存 · 待推 / 已推洛谷 / 失败待重试；失败不轰炸重试
  • 支持 Markdown：标题、粗体、斜体、行内代码、代码块、链接、列表、引用

渲染器内置在 assets/local.js，不引任何 CDN，断网可用

  • 发评论需过算术验证码（纯前端，离线可用）
  • 说明：前端验证码只防误触与简单脚本，真正的鉴权靠 token

4. 主页与题目

  • 主页仿洛谷默认风格但不重合，包含：最近文章、犇犇、题目入口、公告、比赛
  • problems.html：题目列表 + 附件（库中缓存）+ IDE 模式
  • IDE：C++ / Python / C 三语言切换、行号、模板、提交按钮
  • 本地评测（离线兜底）：浏览器内不真编译，用库中 site/data/judge_cases.json

的 std 期望输出做对照；选测试点或粘贴输出即可比对

  • 真编译 = 借洛谷 IDE，用你自己的账号（第 10 条）：要求联网且已登录洛谷。

点「洛谷 IDE 真编译」/「提交洛谷评测」→ 先过确认门 → 新窗口打开洛谷域下的页面 （同源，登录态自动生效）→ 代码已复制到剪贴板，粘贴后由洛谷 IDE 编译 / 评测。 静态站不 fetch 洛谷、不读 cookie、不碰内部 API。入口在「设置」里可自行确认

  • 无网时「编译环境」面板内置国内易联镜像清单，可一键复制 / 主动点击探测可达性
  • 题目页附「已知 hack」（讨论区 / 工单题解），复用甲类反例数据

5. std 投稿与审核

submit.html 投工单 → 本地入队 → 与原 std 对跑比较 → 去除 WA 与 不优 → 添入可选项 → 本人人工审核无错 → 迁入 std。 脚本不自动迁入。详见《std工单与迁入流程》。

5b. 后果自担确认门（第 11 条）

任何写操作 / 借账号动作前会弹确认门，列明动作、目标、用谁的账号、 会在洛谷留下什么公开痕迹、可能触发风控/封号、版权责任。 必须勾选「我已阅读并自行承担全部后果」并输入 「我自担」 才执行； 默认每次确认，你也可主动选择「本次会话不再重复」（责任仍归你）。 「设置 → 查看本地审计」可看留痕（仅存浏览器，不上传）。

确认门是明示同意与责任划分，不是安全边界；真鉴权仍靠 token。 验证码同理，只防误触。

5c. 用 Action 代提交 luogu（第 12 条）

运行态自己加、自己下载：静态站只是壳，GitHub Actions runner 就是现成运行态， 也可以把 tools/luogu_submit.py 下载到本机自己跑。项目按单人自用设计。

  1. 写评论 / 发文 / 用洛谷 IDE 真编译 → 都会先过自担确认门（勾选 + 输入「我自担」）
  2. 文章页点「导出待推队列（给 Action 用）」→ 下载 outbox-YYYYMMDD.json
  3. 把文件放进仓库 site/data/outbox/ 并 push
  4. 仓库 → Actions → 「代提交 luogu · 需本人确认」→ Run workflow：
  5. confirm 填 I_UNDERSTAND_AND_ACCEPT_ALL_RISK
  6. dry_run 选 false
  7. kind 选 comment / publish / judge / all
  8. 首次使用先在 Settings → Secrets 添加：

LUOGU_COOKIE、LUOGU_CSRF、LUOGU_UID、LUOGU_SUBMIT_ENDPOINT； 洛谷 IDE 端点放 Variables 的 LUOGU_IDE_ENDPOINT。端点按你登录后洛谷当前页面填写，仓库不编造。

  • push 触发只预览，不向洛谷发任何写请求；只有手动触发 + 确认值才真提交
  • 低频：2.0~3.5s 抖动、每 20 次小憩、403/降级立即停、失败不轰炸重试
  • 状态回写到 site/data/outbox/_状态.json，已提交 / 失败待重试 / 预览 可核对
  • 你自行确认、自行承担全部后果；项目不代持会话、不认人只认 token

6. 本地操作面板（单人自用）

admin.html：审 std、删资源、按 uid / 用户名 search。 用户名搜不到时可在洛谷评论里用 @ 搜索（低频、无风险、仅必需时用 本人持有的低频检索账号（凭据仅存 Secrets / 本机））。只认 token 不认人：没配 token 时面板只读。 低频检索账号标识见《本人操作与 token 约定》，仓库内无任何凭据。

7. 图片与附件

不全量抓取：只在正文里遇到才保存，落到 site/assets/img/。 空间不够且无法扩容时按 题面 > 题解 > 学术类文章 > 其它 保留。 详见《图片按需抓取与优先级淘汰》。

8. 数据与同步

本库自己就是数据源（最终要求第 1 条），维护文章 / 讨论区 / 题面 / 工单。 联网用户浏览时抓取所浏览内容、延迟维护，源已删则本地也删； 条款见《隐私声明与数据处理条款》「此条」。爬取由 GitHub Actions 的 on: schedule 自持触发，不用发消息激活。

10. 常见问题

问题回答
为什么页面不自动登录洛谷？本地优先 + 出口限制；且避免高频请求触发风控
为什么 IDE 不能真编译？浏览器没有编译器；真编译由你接评测 API
为什么有些条目「正文待补录」？低频逐批取回中，编号已登记不会漏
签名是加密签名吗？不是，是 sha256 内容完整性校验值
断点续传在哪？site/data/crawl_state.json，丢一次 run 不丢进度
想改爬取频率？.github/workflows/crawl_tick.yml 的 cron 与 crawl_daemon.py 参数

附 · 自己验证代提交链路

python3 tools/verify_submit.py：本地假端点跑一遍，确认「未确认跳过 / 预览不 POST / 真提交回写 / 幂等」，不向洛谷发任何请求。改过 tools/luogu_submit.py 后建议跑一次。
