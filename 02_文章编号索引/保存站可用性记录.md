# 保存站（luogu.me）可用性实测记录 · 第 14 批

> 用户问「可以用保存站啊，比如你 2 秒一次就还好吧」。
> 本轮按 **2 秒间隔**低频探测了 8 个端点 + 4 个内置通道页面，结论如下。
> 结论：**瓶颈不是频率，2 秒一次也解决不了**。

## A. curl 直连（每次 sleep 2，共 8 次）

| # | URL | HTTP | 返回 |
|---|---|---|---|
| 1 | `https://www.luogu.me/` | **403** | `{"title":"Request denied","status":403,"detail":"No policy rule matched the request","reason":"policy_default_denied"}` |
| 2 | `https://www.luogu.me/article/sfifnfaa` | **403** | 同上 |
| 3 | `https://api.luogu.me/article/query/sfifnfaa` | **403** | 同上 |
| 4 | `https://www.luogu.me/api/article/query/sfifnfaa` | **403** | 同上 |
| 5 | `https://www.luogu.me/help` | **403** | 同上 |
| 6 | `https://luogu.me/article/sfifnfaa` | **403** | 同上 |
| 7 | `https://www.luogu.me/article/query/sfifnfaa` | **403** | 同上 |
| 8 | `https://www.luogu.com/article/7p4p6gdm` | **403** | 同上（连 luogu.com 直连也被同一策略层拒） |

关键点：`policy_default_denied` 是**出口策略网关**的默认拒绝，不是站点限流、
不是 429、不是验证码。换 UA、换路径、降频到 2 秒都不会变。

## B. 内置取回通道（web_fetch，与 curl 不同链路）

| 页面 | 结果 |
|---|---|
| `https://www.luogu.me/` | **可读**，但只有站点说明与公告 |
| `https://www.luogu.me/article/sfifnfaa` | 只返回**导航骨架**：「主页 / 搜索 / 文章广场 / 猜猜犇 / 统计数据」「本网站已运行 56102522 秒」「我们需要您的许可…」，**无题号、无思路、无代码** |
| `https://www.luogu.me/articles` | SPA 骨架，无文章列表、无编号 |
| `https://www.luogu.me/square`（文章广场） | SPA 骨架，明确「下面没有列出任何文章编号或标题」 |
| `https://www.luogu.me/statistics` | SPA 骨架，无归档总数 |
| `https://www.luogu.me/help` | 只有导航，无接口路径说明 |
| `https://www.luogu.me/search?q=P5015` | SPA 骨架，无搜索结果 |
| `https://www.luogu.com/problem/P1055/solution` | 无法获取（需登录 / 类型不支持） |
| `https://www.luogu.com/article/<lid>` | **可用**：本轮逐字取回了 `g8gclrnk`、`88laurj5`、`2edysvbn`、`z3dolqp8` 的完整代码 |

## C. 保存站自己的公告（首页逐字引用）

> 「近期有大量 AI 自动化程序不断请求保存 API,导致队列堵塞。」
> 「我们正在实现合适的解决方案。」
> 「Save everything, keep it alive.」

也就是说站点**已经因为自动化请求降级**。即便 2 秒一次在我这里能通，
去打保存 API 拉全量也正好撞在它明说的问题上。

## D. 结论与落地

1. **当前不能把保存站当批量数据源**：直连被策略拒绝；文章页/列表页/搜索页全是
   SPA 骨架，正文与编号靠 JS 调保存 API；站点自己挂着降级公告。
2. **「2 秒一次」已做成可配置参数**：`site/lowfreq_fetch.py` 默认 `--delay 2.0`，
   `--base` 可切保存站或 luogu.com，有序队列、断点续传、403/429/降级公告即停、
   不遍历编号空间、不并发、不登录。等你在**能正常访问保存站的网络**里跑，
   它就是你那句「可以用保存站」的落地形态。
3. 本轮继续用可直读的 `luogu.com/article/<lid>` 逐篇补录（第 14 批 3 篇），
   并把两个原本「代码取不全」的登记条目补全验证了。
4. **不刷保存 API、不登录、不提交**——这一条不因降频而放宽。
