- **口径**：甲（已 hack）/ 乙（轻微笔误·主动防抄袭，单列）/ 丙（未 hack）三类

## 「枚举」的确切含义

对**已发现的全部编号**做有序编目（题号升序 → 编号字典序），并逐条判定是否题解；
**不是**对 36^8 编号空间或全站做高频遍历。新增编号按低频逐篇补录，见
`02_文章编号索引/判定口径.md` 与 `06_离线复现说明.md`。

### 本人不用提交（第 13 条）

**首次配置一次，之后无需任何手动提交动作：**

1. Settings → Secrets 写一次 `LUOGU_SUBMIT_CONSENT=I_UNDERSTAND_AND_ACCEPT_ALL_RISK`
   （一次性授权，长期有效），以及 `LUOGU_COOKIE` / `LUOGU_CSRF` / `LUOGU_UID` /
   `LUOGU_SUBMIT_ENDPOINT`；端点按洛谷当前页面填，**不编造内部 API**
2. 网页「设置」填一次 GitHub **fine-grained token**（仅本仓库 Contents 读写，只存浏览器本地）
3. 之后：写评论 / 发文 / 洛谷 IDE 评测 → 过「我自担」确认门 → 点「导出待推队列」
   → **自动写入仓库 `site/data/outbox/`** → push / 定时触发 `.github/workflows/submit_to_luogu.yml`
   → **自动低频代提交 luogu**

- 不用 push、不用手动跑工作流、不用每次填确认值；每 6 小时定时兜底重试「失败待重试」
- **未配置 consent → 永远只预览**，不向洛谷发任何写请求
- 低频 2.0~3.5s 抖动 / 每 20 次小憩 / 403·降级即停 / 失败不轰炸重试 / 幂等
- 仅「真提交且确有发出」才回写状态，避免无意义提交与竞态
- `python3 tools/verify_submit.py`：本地假端点类对拍（跳过 / 预览 / 提交 / 幂等 / 不打印凭据）

**本人自行确认、自行承担全部后果。** 仓库内不含任何账号、cookie 或令牌。

详见 `00_总览/帮助手册.md` 5c、`00_总览/架构可达性测试报告.md`、`api/API契约.md`。

## 兜底 · 本人自行上传 token、自己授权（第 14 条）

自动化里**唯一不能由我代劳的是授权本身**：`LUOGU_SUBMIT_CONSENT` 表示「本人确认并自担后果」，
代填等于替你确认；洛谷登录态我也没有、也不接收。**我不接收任何 token 明文。**

| 用途 | 保存路径 |
|---|---|
| 前端自动入库（GitHub fine-grained token） | 网页「设置」里填 → 浏览器 `localStorage["ll:gh_token"]`，无文件、不进仓库 |
| 洛谷凭据 + 一次性授权 | 仓库 **Settings → Secrets and variables → Actions**：`LUOGU_SUBMIT_CONSENT` / `LUOGU_COOKIE` / `LUOGU_CSRF` / `LUOGU_UID` / `LUOGU_SUBMIT_ENDPOINT`，IDE 端点放 Variables `LUOGU_IDE_ENDPOINT` |
| 本机运行态 | `~/.config/luogu_submit/env`（`chmod 600`，仓库外）；仓库内 `credentials/local.env` 已被 `.gitignore` 排除 |

填一次即可；**未配置 consent → 永远只预览**，不向洛谷发任何写请求。
完整步骤见 `00_总览/帮助手册.md` 5d。
