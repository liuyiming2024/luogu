## 2. 甲类 · P1102 `dxk2a7a8`

### 2.1 代码（逐字取回）

```cpp
sort(shu, shu+n, cmp);            // cmp: a > b，降序
int t=0, w=1;
long long sum=0;
while(w<n){
    if(shu[t]-shu[w]>c) t++;
    if(shu[t]-shu[w]<c) w++;
    if(shu[t]-shu[w]==c){
        tj=wj=0; st=t, sw=w;
        for(int i=t; shu[i]==shu[st]; i++){ tj++; t++; }
        if(c==0) wj=1;                       // ← 只置 wj，w 不推进
        else
        for(int i=w; shu[i]==shu[sw]; i++){ wj++; w++; }
        sum += (long long)tj * (long long)wj;
    }
}
printf("%lld", sum);
```

### 2.2 反例（题面 `1≤N≤2×10^5`，`C` 与数列元素均为正整数范围）

| 输入 | 正确 | 实际 |
|---|---|---|
| `1 / 0 / 5` | `1` | `0`（`w=1` 不小于 `n=1`，循环根本不进） |
| `2 / 0 / 5 5` | `4` | **空输出，rc −11（SIGSEGV）** |
| `3 / 0 / 5 5 5` | `9` | **空输出，rc −11** |
| `3 / 1 / 1 5 3` | `0` | **空输出，rc −11** |

题面 `A−B=C` 的正确口径是 `sum(cnt[x+C] for x in arr)`；`c=0` 时应为 `Σ cnt[x]²`，而题解令 `wj=1`、`sum += tj*1`，只数了一次连续段长度，**既漏计数又不推进 `w`**，让 `t` 一路扫过 `shu` 的尾部零区，直到越界读崩。

**批量枚举**（n≤5、值域 1..4、c=0..3，共 5456 组）：干净 WA 4 组（全是 `n=1,c=0`），其余 **2208 组越界**。**300 组随机（n≤60, c=0..10）64 组不一致**，且 `c>0` 也崩，不只是 `c=0` 特例。

### 2.3 划界：为什么归甲

- 只补 `wj=tj; w=t;`（改一处表达式）后重跑 300 组，**仍 53 组挂**；
- 换成标准 `map` 计数 `Σ cnt[x]·cnt[x+C]`（**重写核心逻辑**）才 0 不一致。
- 三个独立 `if`（非 `else if`）连锁推进、连续段统计与 `w` 同步、以及 `c=0` 的平方计数，是**多处结构性缺陷**，不是「改一处字符或数字 / 补一条初始化」能修的；
- 也不是主动防抄袭 / 打表 / 展示形态（作者正文正经讲双指针思路）。

→ 甲类。

## 3. 乙类 · P1423 `4fj37pww`（本批最隐蔽的一处）

### 3.1 代码（逐字取回）

```cpp
int L, R=INT_MAX, mid;
double target, dist, per=2;
while(R>=L){
    mid=(L+R)/2;
    for(int i=1;i<=mid;i++){
        dist += per;
        per *= 0.98;
        if(dist>target) break;          // 剪枝
    }
    if(dist>target) R=mid-1;           // ← 二分判定
    else L=mid+1;
    dist=0; per=2;
}
cout<<L;
```

题面「游到距离 s」= 累计距离 **达到或超过** s，标准循环解写的是 `while(d<s){...}`，即 `d>=s` 停止。题解全程用**严格大于** `>`，于是二分求的是「最小使累计 `> s` 的步数」，比正确答案多 1 步——**当且仅当 s 恰好等于前 k 步累计和**。

### 3.2 反例（全部是题面内的合法实数）

| 输入 s | 正确 | 实际 |
|---|---|---|
| `2` | `1` | `2` |
| `3.96` | `2` | `3` |
| `5.8808` | `3` | `4` |
| `7.763184` | `4` | `5` |
| `9.60792032` | `5` | `6` |
| `11.4157619136` | `6` | `7` |
| `13.187446675328` | `7` | `8` |
| `14.923697741821439` | `8` | `9` |

官方样例 `4.3 → 3`、以及 `0.5 / 1 / 1.9 / 2.01 / 10 / 50 / 99 / 99.9` 全部通过。**200 组随机（6 位小数）原版 0 不一致**——因为随机实数几乎不可能恰好命中那些部分和；这类缺陷只能靠构造边界点挖出来。这正是历批「定点 + 随机」两套都要跑的理由。

### 3.3 划界：为什么归乙

- **只把外层判定改成 `if(dist>=target)`（补一个 `=`）**，8 个定点全部恢复正确，200 组随机 0 不一致；两处都改同样 0 不一致。
- 反过来只改内层剪枝会**死循环**（`dist==target` 时提前 break，外层仍判 `>` 为假 → `L=mid+1` 跳过答案，二分永不收敛）——所以最小修复恰恰是改外层那一处。
- 与第 6 批 P1563 `x<0`→`x<=0`、第 7 批 P1003 `10020`→`100005` **完全同型**：改一处字符/数字即逻辑正确。

→ 乙类单列，反例只作验证数据，不计甲类命中。想按「反例无限多」把它挪进甲，说一句即可。

## 4. 丙类逐篇（5 篇）

### 4.1 P1328 `0z8yhoc0`
`int w[5][2]={{1,4},{2,4},{0,3},{0,1},{2,3}};` 注释写「赢每个的数」，实际语义是 **「能赢 a 的手势」**：`if(b[i]==w[a[i]][j]) ansb++`、`if(a[i]==w[b[i]][j]) ansa++`。逐项核对题面胜负表（0 剪刀赢 2 布/3 蜥蜴人、1 石头赢 0 剪刀/3 蜥蜴人、2 布赢 1 石头/4 斯波克、3 蜥蜴人赢 2 布/4 斯波克、4 斯波克赢 0 剪刀/1 石头）后，反查表与代码自洽。两个官方样例 `6 2` / `4 4`、n=200 满规模、300 组随机 0 不一致。
> 逐字取回里 `for(int i(nb+1;i<=n;i++)` 是页面渲染吞了 `=`，按题解文字补成 `for(int i=nb+1;i<=n;i++)`——补最小外壳，不计缺陷。

### 4.2 P1012 `kckry124`
`bool cmp(string a,string b){ return a+b>b+a; }` + `sort(a+1,a+n+1,cmp)`，`string a[21]` 对题面 n≤20 刚好。独立解用 **n≤7 全排列取最大拼接串**，5 个经典定点（`13 312 343`、`12 121`、`9 98 987`、`1 10 100`、`321 32 3`）+ 300 组随机 0 不一致。

### 4.3 P1204 `gw5uvykg`
按 begin 升序排序后合并区间：`if(m[i].begin <= end)`（相邻区间算连续，符合 `[a,b)` 半开语义）、断开时 `ans2=max(ans2, m[i].begin-end)`、末段再补一次 `ans1`。独立解用**时间轴逐秒标记**扫描最长连续有人段 / 中间空档，300 组随机区间 0 不一致。

### 4.4 P1553 `nxvqnwg8`
`reversef`（倒着扫、跳反转后的前导 0、全 0 时补一个 `0`）处理整数 / 分子 / 分母 / 百分数前；`reverseb`（先正向找第一个非 0 定位 `fro`，再倒着输出）处理小数部分，正好对应「小数去原串前导 0、整数去原串后导 0」的不对称规则。
17 个定点含全部经典边界：`0→0`、`1200→21`、`120.120→21.021`、`0.0012→0.21`、`12.0→21.0`、`120/210→21/12`、`0/120→0/21`、`1200%→21%`、`0%→0%`、`100.000→1.0`、`600/006→6/600`；再加 300 组随机，0 不一致。

### 4.5 P1598 `biep97vd`（Python 3）
`staDic` 统计 A~Z，`ZDic={'Z': staDic.pop('Z')}` 把 Z 单独拿出来处理末尾换行；每层 `print('*', end=' ')` / `print(' ', end=' ')` 输出前 25 列，第 26 列单独 `print('*')` / `print(' ')` 换行。独立解用 `' '.join(cells)` 生成同样的 51 字符行，200 组随机四行输入（含小写、数字、标点）0 不一致。
> 本批唯一非 C++ 题解；按「代码只是辅助」只验核心输出逻辑，语言不构成缺陷。
