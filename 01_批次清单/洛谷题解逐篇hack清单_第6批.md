## 2. 乙类重点：P1563 `xmumv7ok`

### 2.1 主代码确实有确定性 WA

逐字取回的核心（1-based 下标，`x` 是当前小人编号）：

```cpp
if(z>=0){
    if(z>=n)z=z%n;
    x=x+z;
    if(x>n)x=x%n;
}else{
    z=-z;
    if(z>=n)z=z%n;
    x=x-z;
    if(x<0)x=n+x;        // ← 只补了负下标
    if(x>n)x=x%n;
}
printf("%s",a[x]);
```

`x` 取 1..n，但 `x-z` 可能恰好等于 **0**：此时 `if(x<0)` 不成立，`a[0]` 从未读入过（输入从 1 开始），输出空串或残留内容。

**题面内最小反例**（n=3、m=1，全部朝内）：

```
3 1
0 aa
0 bb
0 cc
0 1
```

期望 `cc`（1 号朝内、向左数 1 人 = 3 号），**实际输出空串**。另一条 `4 1 / 1 p / 1 q / 1 r / 1 s / 1 1` 期望 `s`、实际空串。300 组随机中 **42 组不一致**，均为这条路径。

### 2.2 为什么归乙不归甲

- **改一处即修复**：`if(x<0)` → `if(x<=0)`（插入一个 `=`），本地改完重跑同样 300 组，**0 不一致**。按第 4 批划界（改一处字符或数字即逻辑正确）→ 乙类。
- **作者主动改代码绕过**：原文自述「怎么第 4 个点过不去???Σ(ŎдŎ|||)ﾉﾉ 其实，我们可以把最后的输入换成……对，我**偷偷下载了测试点数据**(╥_╥)」，随后给出

```cpp
if(n==20&&m==1000&&a[1][0]=='l'&&…&&a[1][9]=='e') printf("libvpmvqve");
else printf("%s",a[x]);
```

硬编码特判只对那一个测试点有效，走 `else` 时主代码缺陷依旧。这正是你要求单列的「主动防抄袭 / 打表」形态。

> 按第 5 批 P1049 `v3wxayi3` 的先例：**有确定性反例但属该形态，反例只作乙类验证数据，不计甲类命中**。若你想按后果把它挪进甲，说一句即可。

## 3. 丙类逐篇（7 篇）

### 3.1 P1909 `h8ic4o0m`
三种包装分别 `if(n%a1!=0) da=(n/a1+1)*a2; else da=(n/a1)*a2;`，再 `min`。独立解 `min((n+a-1)//a*b)`。样例 1→54、2→18407、3→89991 全对，300 组随机 0 不一致。
**注意**：搜索摘要里 b 段被渲染成 `dc=(n/c1+1)*c2`，逐字正文并非如此（见 §0②）。

### 3.2 P1424 `apqvl7bn`
```cpp
for(int i=1;i<=k;i++){
    if(n!=6 && n!=7) s+=250;
    if(n==7) n=1; else n++;
}
```
逐天模拟、周 6/7 休息、周 7 后回 1。独立解按 `(x+d-1)%7+1` 判定。样例 `3 10 → 2000` ✓，周六/周日起点、n=100000（答案 17857000，int 未溢出）全对，200 组 0 不一致。

### 3.3 P1093 `tehqdnw3`
把排序键压成一个整数：
```cpp
b[i]=(a[i]+x+y)*1000000 + a[i]*1000 + n-i;
sort(b+1,b+n+1);
for(int i=n;i>n-5;i--) cout<<n-b[i]%1000<<" "<<b[i]/1000000<<endl;
```
`n ≤ 300`、语文 ≤ 100，故 `语文*1000+(n-i) ≤ 100299 < 10^6`，不会进位污染总分位；`n-i` 让学号小的键更大（降序输出时在前）。2 个官方样例（含总分/语文并列）全对，200 组随机 0 不一致。

### 3.4 P2141 `b7py0ojt`
桶标记所有 `i<j` 的两数之和（和 ≤10000 才标），再统计集合里落在桶中的数——符合「有多少个数恰好等于另外两个**不同**数之和」，与「有多少对」的 30 分错解区分开。300 组随机（值域内互异）0 不一致。

### 3.5 P1059 `6t0wrb4o` / `05bplzw1`
前者排序后 `if(a[i]!=a[i-1]) b[++j]=a[i]`（依赖全局 `a[0]=0`，题面数 ≥1 成立）；后者直接 `set<int>` 去重。两篇各 250 组 0 不一致。

### 3.6 P1089 `1ndosdfs`
```cpp
if(me<0){ me=-i; break; }
mom += me/100*100;  me %= 100;
… else printf("%g", me + mom*1.2);
```
顺序正确（先扣预算、再判超支、最后存整百）。2 个官方样例 `-7` / `1580` ✓，全 0 预算 → 4320 ✓，全 349 → -1 ✓，300 组随机 0 不一致。`%g` 与 `mom*1.2` 的浮点疑虑见 §0①，实测不成立。
