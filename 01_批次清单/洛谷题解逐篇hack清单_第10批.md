## 2. 甲类 · P1152 `h7y41tog`

### 2.1 代码（逐字取回）

```cpp
int n, a[1005];
cin >> n;
if (n == 1) { cout << "Jolly"; return 0; }
for (int i = 1; i <= n; i++) cin >> a[i];
int dif[1005];
for (int i = 1; i <= n - 1; i++) dif[i] = abs(a[i + 1] - a[i]);
sort(dif + 1, dif + n);
bool vis[10000005] = { 0 };            // ← 10MB 局部数组
for (int i = 1; i <= n - 1; i++) vis[dif[i]] = 1;   // ← dif 可达 2e8
for (int i = 1; i <= n - 1; i++) if (!vis[i]) { cout << "Not jolly" << endl; return 0; }
cout << "Jolly" << endl;
```

题面（`1≤n≤1000`，`−10⁸≤aᵢ≤10⁸`，官方题面写「**每组测试数据**」）：相邻差绝对值可达 **2×10⁸**，而 `vis` 只有 `10000005` 个 bool。

### 2.2 三层独立缺陷（分层实测）

| 层 | 实测 | 结论 |
|---|---|---|
| ① 栈溢出 | `ulimit -s` = **8192 KB**，`bool[10000005]` ≈ 10MB 局部变量 → **任何输入** SIGSEGV，连官方样例 #1、`n=1` 都崩 | 环境相关但题面内合法输入确定性 RE |
| ② 下标越界 | 把 `vis` 改成 `static`（挪出栈）后：官方样例 / `n=1` / `diff=1e7` / `diff=10000005` 全部正确；但 `diff=2e8`、`diff=−1e8→1e8` 仍 **SIGSEGV** | 与栈无关的逻辑必然缺陷 |
| ③ 多组漏读 | static 版喂 `4/1 4 2 3` + `5/1 4 2 -1 6` + `1/9`，只输出 `Jolly` 一行，缺 `Not jolly`、`Jolly` | 只读一组，未按题面读到 EOF |

### 2.3 反例（全部题面内合法输入）

| 输入 | 正确 | 实际（逐字原文版） |
|---|---|---|
| `4 / 1 4 2 3`（**官方样例 #1**） | `Jolly` | 空输出，rc −11 |
| `5 / 1 4 2 -1 6`（**官方样例 #2**） | `Not jolly` | 空输出，rc −11 |
| `1 / 7`（`n=1` 特判分支） | `Jolly` | 空输出，rc −11 |
| `2 / 0 200000000` | `Not jolly` | 空输出，rc −11（static 版同样崩） |
| `2 / -100000000 100000000` | `Not jolly` | 空输出，rc −11（static 版同样崩） |

**200 组随机（含 ±1e8 量级元素）原版 200 组全挂**，修复版 0 不一致。

### 2.4 划界：为什么归甲

- **不能靠「把数组开大」修**：`static bool vis[200000005]`（约 200MB）虽然在本沙盒能跑通样例，但题面内存限制 **125MB**，直接 MLE；
- **不能靠改一处修**：只挪到静态区 → 大差输入仍崩；只改数组大小 → 爆内存；还要补 `while(cin>>n)` 多组循环；
- 唯一可行修复是**重写核心**：`sort` 差值后逐一比对 `d[i]==i+1`（或 `set`/`map`），再改输入循环。修复版 200 组随机 + 多组输入全对。
- 三层缺陷彼此独立，不是「改一处字符或数字 / 补一条初始化」能修的；也不是主动防抄袭 / 打表 / 展示形态（作者正文正经讲桶标记思路）。

→ 甲类。

> 关于输入组数：洛谷 `problemnew/show/1152` 题面写「每组测试数据」，部分镜像写单组。为避免依赖这个歧义，**主判据用单组输入即可触发的 ①② 两层**；第 ③ 层按官方题面登记，不计入甲类反例编号。

## 4. 丙类逐篇（8 篇）

### 4.1 P1200 `ictzayja`（C++）
`int cnt1=1,cnt2=1` 累乘 `s[i]-'A'+1`，最后 `cnt1%47 == cnt2%47`。题面字符串≤6 位大写，理论最大 `26⁶ = 308,915,776 < 2³¹−1`，**不逐步取模也不会爆 int**。两个官方样例、`ZZZZZZ`、`AAAAAA`、单字母 + 300 组随机 0 不一致（随机中观测最大乘积 56,908,800）。

### 4.2 P1200 `vckbob2z`（Pascal）
`x:=x*(ord(st1[i])-64) mod 47` **每一步都取模**，等价逻辑用 Python 复刻 300 组 0 不一致。与 `ictzayja` 是同题两种写法，一个不取模一个逐步取模，题面范围内都正确 → 正好凑成一组对照。

### 4.3 P1424 `apqvl7bn`
`for(i=1;i<=k;i++){ if(n!=6&&n!=7) s+=250; if(n==7) n=1; else n++; }`。题面 `1≤x≤7, 1≤n≤10⁶`，`s` 最大 178,571,500 < INT_MAX。8 个定点含 `n=1e6` 上限、`1 7`、`1 14`、周末起点，200 组随机 0 不一致。

### 4.4 P1425 `nobyk23w`（C 版 + C++ 版，逐字两块都验）
`w_time = (eh*60+em)-(sh*60+sm)` 全转分钟后 `uset/60`、`uset%60`。两块代码逻辑一致，仅输入输出语句不同。6 定点含官方样例 `12 50 19 10 → 6 20`、`1 59 2 0`、`0 59 1 0` 借位边界，C 版与 C++ 版各 193 组随机 0 不一致。

### 4.5 P1425 `beuv9jew`
借位法：`if(d>=b) y=d-b; else { d+=60; y=d-b; c--; } x=c-a;`。与上篇全转分钟法互为对照，6 定点 + 290 组随机 0 不一致。注释把 `x`/`y` 说反（见 §3），代码正确。

### 4.6 P1055 `kfg4ugka`
`scanf("%1d-%1d%1d%1d-%1d%1d%1d%1d%1d-%c", ...)` 逐位读入 9 个数字与识别码，`k=(a*1+...+i*9)%11`，`k==10` 输出 `X`。7 定点含官方样例 `0-670-82162-4`、识别码为 `X`、故意改错识别码、全 9 / 全 0；300 组随机（一半故意改错）0 不一致。

### 4.7 P1179 `59x93a43`
仅验作者标注「**AC 代码应该是这样的**」的第二块：`n=y` 做替身，`while(n!=0)` 分离各位统计 `2`。7 定点含官方样例 `2 22 → 6`、`2 100 → 20`、`1 100000 → 50000`（题面上限全量），200 组随机 0 不一致。

### 4.8 P1059 `6t0wrb4o`
`sort(a+1,a+1+n)` 后 `if(a[i]!=a[i-1]) b[++j]=a[i]`，靠全局 `a[0]=0` 保证首个元素被收进 `b`。逐字取回补齐被吞掉的 `b[++j]` / `cout<<j` / 输出循环，补最小外壳 `int j=0;`。5 定点含官方样例、全重复、逆序，300 组随机 0 不一致。
