## 一、翻案：`yk90rg78`（P1002 过河卒）第 2 批判甲是误判

### 错在哪

第 2 批的描述是「`f[0][0]=1-ctrl[0][0]` 写在 DP 双重循环**之后**，整张表以 0 起算完
才改起点，输出恒 0；`6 6 3 3` 期望 6、实际 0」。

原文逐字代码（`<pre>` 块 1，1392 字节）：

```cpp
for(int i=0;i<=n;i++)
    for(int j=0;j<=m;j++){
        if(ctrl[i][j])continue;
        if(i!=0)f[i][j]+=f[i-1][j];
        if(j!=0)f[i][j]+=f[i][j-1];
    f[0][0]=1-ctrl[0][0];
    }
    cout<<f[n][m];
```

`f[0][0]=1-ctrl[0][0];` **在 j 循环体内**，且位于两条状态转移之后。
i=0、j=0 的第一轮：两条 `if` 都跳过，随后把起点置 1；
之后每轮重设为同一值（无害，f[0][0] 不再被累加）。马控制起点时
`if(ctrl[0][0])continue;` 跳过该行，f[0][0] 保持 0 —— 也正确。

**是转录版把这一行挪到了循环之外**，才造出「输出恒 0」的假 WA。
这是第 5 批「漏抄 `dp[i][0]=1` 造出 103 组假 WA」的同型错误，
只是这次错的是**语句层级**而不是漏行：转录位置也是语义。
