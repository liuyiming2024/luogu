# 隐私声明与数据处理条款

> 最终要求第 7 条锁定：「在隐私声明中提供**此条**」——即把延迟维护、
> 源已删则本地也删、跟踪保存站工作流与洛谷工单这一整套行为，作为**明示条款**写在这里。

## 此条 · 延迟维护与同步条款

1. **本地优先**：文章、评论、发文先保存在使用者本地（浏览器缓存 + 本库），
   离线可完整浏览与撰写。
2. **延迟维护**：联网用户浏览内容时，本站会把**所浏览的内容**抓取回本库，
   但采用**延迟**方式（低频、错峰、窗口化），不做实时高频同步。
3. **源已删则本地也删**：当线上数据源（洛谷 / 保存站）确认某条目已删除时，
   本地副本按同一规则删除；删除时保留一条「已移除」审计记录，不保留正文。
4. **跟踪工作流**：记录最近的保存站工作流状态与洛谷工单动态，仅用于判断
   数据源可用性与同步时机，不用于识别或追踪自然人。
5. **借用保存站流量**：以保存站流量做延迟维护，本地最新信息推送线上数据源；
   不因同步额外提高对任一方的请求频率。

## 评论推送条款（第 9 条口径）

- **评论持久化直接推洛谷**：洛谷文章评论区为权威持久层，本库不另建评论数据库
- 推送使用**用户个人账号**的登录态，由能出网且持有该登录态的一端执行；
  静态页面不直连洛谷、不代持会话
- 本地保留评论副本与待推队列，仅用于离线阅读与断点续传；
  「已推洛谷 / 待推 / 失败待重试」状态对用户可见
- 推送为**低频、人工确认、可一键关闭**；失败不轰炸重试
- 低频检索账号不参与评论推送

## 用户自担风险条款（第 11 条口径）

> **让对方自己确认后果、让对方自己承担。**

1. 所有**写操作**（评论推洛谷、发文回推、std 投稿外发、删资源）与
   **借账号动作**（洛谷 IDE 真编译、提交洛谷评测）执行前，页面必须弹出确认门，
   明示：动作名称、目标地址、将使用谁的账号、会在洛谷留下什么公开痕迹、
   可能触发的风控/限流/封号、以及内容版权与合规责任。
2. 必须**主动勾选**「我已阅读并自行承担全部后果」并**输入「我自担」**才执行；
   取消即不执行，**默认每次确认**。
3. 用户可主动勾选「本次会话内不再重复确认」——这是用户自己放宽提示，
   **责任仍完全由用户承担**，不因跳过弹窗而转移。
4. 本地保留**自担审计留痕**（时间、动作、内容摘要、确认结果），仅存浏览器，
   不上传、不含账号密码/cookie/token。
5. 确认门是**明示同意与责任划分，不是安全边界**：纯前端可绕过，
   真正的鉴权仍靠 `Authorization: Bearer <token>`。
6. 平台仍保留**低频、默认关闭、失败不轰炸重试**作为默认保护；
   用户自行放宽频率或强行重试所致后果，同样由用户承担。
7. 低频检索账号不参与评论与 IDE；IDE / 写操作一律用**用户个人账号**。

## Action 代提交与自担后果（第 12 条）

- **运行态由使用者自行添加 / 下载**：Actions runner 或本机脚本；静态站不承担运行态
- 凭据（`LUOGU_COOKIE` / `LUOGU_CSRF` / `LUOGU_UID`）只存 **Settings Secrets / 本机环境变量**，
  不进仓库、不打印、不上传
- 待推队列只含本人已确认的内容；配了 fine-grained token 时经确认门**自动写入仓库**（连 `api.github.com`，非洛谷）；未配则下载文件由本人放入
- **本人首次一次性授权**（`LUOGU_SUBMIT_CONSENT` Secret）后，push / 定时自动真提交；
  **本人不用 push、不用手动跑工作流、不用每次填确认值**
- 未配置 consent 时**永远只预览**，不向洛谷发任何写请求
- **本人自行确认并自行承担全部后果**：公开评论 / 提交记录、平台频次限制、风控、
  账号限制与内容责任均由本人承担；项目仅提供本地工具与队列
- 项目按**单人自用**设计，不设角色体系，公开产物不出现角色字样、不明文登记账号

## 账号与隐私信息

- 登录使用 **cookie 或账密**，账号等隐私信息**只在本地缓存**，支持子页面不重复登录
- 使用 cookie 时，部分信息（手机号 / uid / 用户名等标识）**不显示**
- 未登录或无法联网获取头像时，使用**洛谷默认头像**
- 用户名：联网时从洛谷获取；无网时用缓存或登录时的标识信息
- **无效状态（无缓存且无网）**：用户名显示灰色
- 本站**不向仓库写入任何密码、cookie、token**；公开仓库里只有标识与结构

## 鉴权

所有管理与 API 能力**只认 token 不认人**：服务端仅校验
`Authorization: Bearer <token>`，不校验自然人身份。见 `api/API契约.md`。

## 请求频率

沿用既定礼貌节奏：2.0~3.5 秒随机抖动、每 20 次小憩、50 分钟窗口 /
15 分钟静默、403/降级即长退避 30 分钟。页面**加载时零外网请求**。
