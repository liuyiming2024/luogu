# 图片按需抓取与优先级淘汰

## 抓取原则

**不做全量抓取。** 只在文章、题面、讨论区等页面**正文里遇到图片引用时**才保存该图片；
保存时记录来源 URL、所属条目、sha256 与抓取时间，随条目一起纳入本库数据源。

- 低频：随内容取回顺带保存，不单独开图片遍历任务
- 离线可用：图片落到 `site/assets/img/`，页面引用本地副本；原 URL 仅作来源留痕
- 版权：图片版权归原作者 / 洛谷所有，随《归档与版权声明》一并处理；权利人可申请移除

## 空间不够且无法扩容时的保留优先级

```
题面  >  题解  >  学术类文章  >  其它（讨论区 / 犇犇 / 装饰图）
```

淘汰顺序从「其它」开始，逐级回退；**题面附件最后淘汰**。
淘汰只删本地副本与引用映射，不删条目本身的文字、代码块、署名与签名。

## 与「题目附件」的关系

题目页提供页面附件（自己先在库中抓回缓存），附件与图片同样按按需抓取 +
同优先级淘汰处理。详见 `problems.html` 与《全量任务完成清单》。

## 与保存站流量的关系

借用保存站流量做**延迟维护**：本地最新信息推送线上数据源，
不因图片抓取额外增加对保存站 / 洛谷的请求频率（沿用 2.0~3.5s 抖动、
每 20 次小憩、50 分钟窗口 / 15 分钟静默）。
