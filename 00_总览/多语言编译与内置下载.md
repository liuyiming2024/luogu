# 多语言编译与「内置下载」功能

## 有网

- 各语言编译**在线运行**：由使用者配置的评测 API 执行（token 认证，见 `api/API契约.md`）
- 本站不内置任何在线编译服务，也不向第三方裸发代码

## 无网

**提供国内易联、速度快的下载地址，且必须内置为功能，而不是直接甩一个网址。**

实现形态（`site/assets/local.js` 的「编译环境」面板）：

- 内置一份**镜像清单**（多个可达地址 + 适用语言 + 校验值），页面内可选、可一键复制
- 提供「检测可达性」按钮：逐个 `HEAD` 探测并标出最快节点（**仅在用户主动点击时**发起请求，页面加载零外网）
- 下载后由用户在本地完成编译；本站不自动下载、不后台拉包
- 全程离线可用：清单本身随静态站一起打包，断网也能看、能复制

> 说明：具体镜像地址由使用者按所在网络自行维护，仓库只存**结构与检测逻辑**，
> 不写死可能失效的第三方地址，也不假装当前沙盒能访问外部域名。

## 支持语言

**C++ / Python / C**（最终要求第 6 条：无额外指定语言）。
IDE 模式按这三种语言切换高亮与模板，不添加未指定的语言。

## 本地评测（无网）

浏览器内**不做真编译**（没有 g++ / CPython 运行时）。
「本地评测」= 用库中已归档的 **std 期望输出表** 做对照：
用户在 IDE 里粘贴输出，或选择内置测试点，页面把结果与 `site/data/judge_cases.json`
中的期望值比对，给出「一致 / 不一致」。真编译走评测 API 适配器。
