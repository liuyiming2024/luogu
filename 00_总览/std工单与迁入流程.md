# std 工单（投稿）与迁入流程 · 已跑通

> 背景：**取不到官方数据**，正确性以 **std 对拍**为准，不假装手里有官方测试数据。
> 落实最终要求第 2 条；全部跑在本地，零外网、零登录。

## 状态机（已实现）

```
投稿（工单 tools/std/tickets/）
   ↓ 与原 std 多轮对跑（3 轮不同 seed，题面内输入）
   ├─ WA / RE / TLE / CE  → 去除（留首个反例与 rc）
   ├─ 结果正确但不优      → 去除（CPU 或内存明显劣于原 std）
   ├─ 等价（波动带内）    → 不收（无明显优势）
   └─ 不 WA 且明显更优    → 添入「可选项」= 待人工审核
                              ↓ 本人逐条确认
                              ├─ 有错 → 打回 / 去除
                              └─ 无错 → 迁入 std
```

**脚本永不自动迁入**：台账里 `已迁入` 恒为 0，这是自检检查点。

## 判据

| 项 | 口径 |
|---|---|
| 官方数据 | **无**。自写独立正确解 + `cases.py` 生成题面内输入 |
| 对拍 | 每题与「原 std」多轮对跑；输出逐行归一化比对 |
| 去除 WA | 任何题面内确定性 WA/RE/TLE/CE 直接淘汰（沿用甲类口径） |
| 去除不优 | CPU 中位数 ≥ 1.25× 或峰值 RSS ≥ 1.25×，且 3 轮方向一致 |
| 明显更优 | CPU 中位数 ≤ 0.80× 或峰值 RSS ≤ 0.80×，且 3 轮方向一致 |
| 等价 | 0.80~1.25 波动带 → 不收（最小时间/空间、省资源是默认要求） |
| 抗波动 | CPU 时间取 `os.wait4` 的 `ru_utime+ru_stime`，**不用墙钟**；墙钟只用于超时 kill |
| 人工审核 | 本人逐条确认后迁入，脚本不自动迁入 |
