# std 工单与迁入流程 · 题面闸门 + 代审

> 背景：**取不到官方数据**，正确性以 **std 对拍**为准。
> 顺序（最终要求）：**先爬到题面 → 再做 std**；「保证做的是对的，
> 不要说你觉得对它就放」；审核由本地代跑；别人可发工单。

## 一、先爬题面（对面队列）

- `crawl_tick.yml` 加 `--problem-first`：题面按 P 号顺序**排在题解之前**，
  题解只补少量，不再让 60 条题解占满窗口
- 题面 URL 走 `?_contentOnly=1` + `x-luogu-type: content-only`
  （洛谷 API 文档：DataResponse 请求需 `_contentOnly` 或该头）
- `.github/workflows/problem_first.yml`：每 6 小时错峰、2 秒以上间隔，
  **只取题面正文**；`tools/fetch_problem.py` 逐个试有文档依据的端点，
  只有真正解析出含题目字段的 JSON 才落盘，骨架 / 403 / 非 JSON 一律不写文件
- **不制造无用提交**：daemon 收工写「本轮有效产出」到 `/tmp`，
  `crawl_tick` 严格按本轮增量判定；为 0 时跳过重生成与提交。
  `problem_first` 仅在确有新增题面正文时才 commit，否则只留 artifact

## 二、题面证据与闸门（不凭记忆）

`site/data/problems/<PID>.json` 逐字存档题面字段，带原文链接、sha256、
取回端点、时间、**证据等级**。当前三题的证据等级是
「**检索摘录（逐字，待 contentOnly 队列复核升级）**」——
本地出口直连洛谷被策略网关拒、页面取回通道也拿不到题面页，
所以**没有把摘录伪装成队列正文**；正文由对面队列取回后自动升级等级。

`tools/std/problem_gate.py` 是硬闸门，任一题必须全部通过才允许做 std：

| 检查 | 口径 |
|---|---|
| 证据文件存在、sha256 可核对 | 没有题面存档 → 明确「未做」 |
| 范围引用逐字命中 | `std_bank` 的范围声明必须逐字出现在存档题面里 |
| 题面样例实测全过 | 用 std 真跑存档样例，逐字比对 |
| 用例全部 `in_range()` | 题面外输入一律作废 |

### 实测纠错：三处凭记忆写错的范围（这正是「不觉得对就放」）

| 题 | 旧（凭记忆） | 题面逐字 |
|---|---|---|
| P1001 | `a,b 为 int 范围整数`（生成了 ±2³¹ 题面外输入） | **∣a∣,∣b∣≤10⁹**，样例 `20 30 → 50` |
| P1421 | 题名写「买铅笔」 | **「小玉买文具」**；「买铅笔」是 NOIP2016 普及 T1；样例 `10 3 → 5` |
| P1002 | 「起点/终点不被马控制（题面保证）」 | 题面**只保证起点不是马的控制点**，未保证终点；旧版把合法输入误排除 |

三处已按存档逐字修正；`cases.py` 范围引用、样例置顶、机读 `in_range()`
全部与题面存档对齐，并由 `verify_std.py` 做回归检查点。

## 三、状态机（已实现）

```
题面正文（队列 contentOnly）
   ↓ 题面闸门：范围逐字 / 样例实测 / 用例 in_range
   ↓ 闸门未过 → 「不做」，不判、不放
投稿（本地工单 或 external/ 外部工单）
   ↓ 与原 std 多轮对跑（3 轮不同 seed）
   ├─ WA / RE / TLE / CE → 去除（留首个反例）
   ├─ 明显不优（CPU/RSS ≥1.25× 且多轮一致）→ 去除
   ├─ 等价（0.80~1.25 波动带）→ 不收
   └─ 明显更优 → 待人工审核
        ↓ 代审 review.py（证据链复核，不是主观放行）
        ├─ 证据不足 → 打回
        ├─ 题面摘录级 → 准予迁入·**挂起待正文复核**
        └─ contentOnly 正文级 → 准予迁入
             ↓ promote.py（唯一迁入入口，带 guard）
             └─ 备份旧 std → 逐字替换 → 记旧/新 sha256 → 台账已迁入
```

**脚本绝不凭感觉迁入**：`promote.py` 在证据等级不是 contentOnly 正文时
明确拒绝，挂起项不猜不补。当前台账 `已迁入 = 0`。

## 四、代审（本地代跑，别人也能投稿）

- `tools/std/review.py`：逐条复核题面闸门、代码 sha256（防转录位置错）、
  **重跑对拍**、多轮方向一致、六类变异脚本在位；结论带完整证据链
- `tools/std/tickets/external/`：外部工单入口，一个 `.json` + 一份源码，
  不需要账号、不需要联网；`std_pipeline.py` 自动扫描入队
- 前端 `submit.html` 底部同时显示**候选台账**与**代审台账**（只读），
  页面不判定、不迁入

## 六、判据不变

CPU 时间取 `os.wait4` 的 `ru_utime+ru_stime`（**不用墙钟**，避开评测机波动）；
3 轮方向一致才认明显优/劣；WA/RE/TLE/CE 一律去除；
离线站 `problems.html` 本地评测 49 个测试点（含 std 期望表）。

命令与目录见 `tools/std/README.md`。
