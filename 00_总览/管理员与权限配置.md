# 管理员与权限配置

> **只认 token 不认人。** 本页只登记「管理员标识」，**不含任何密码、cookie、token**。
> 凭据只存在于环境变量 / Actions secrets / 使用者浏览器本地缓存。

## 能力

- **审 std**：查看 std 投稿队列，执行「与原 std 对跑 → 去除 WA 与不优的」判定，人工审核无错后迁入 std
- **删资源**：按编号删除文章 / 题面 / 讨论区 / 工单条目；删除时同步清理本地缓存与引用署名
- **增删面板**：网页 `admin.html`，支持按 **uid** / **用户名** search
- **用户名搜不到时**：可在洛谷评论里用 `@` 搜索（低频、无风险请求，仅必需时使用 `liuyiming2024_1`）

## 平台

GitHub / Supabase / Webnote，统一用 **free 版**，权限原则上不设额外限制；
需要更多配额时由使用者提出再调整。

## 鉴权契约

所有管理操作走 `Authorization: Bearer <token>`，**服务端只校验 token，不校验是谁**。
详见 `api/API契约.md`。前端 `admin.html` 在未配置 token 时**只读**，不会误删。
